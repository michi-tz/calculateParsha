# מודול פרשת השבוע למדיה ויקי

מודול זה מחשב את פרשת השבוע הנוכחית או לתאריך מסוים, עם התייחסות לחגים שמחליפים את קריאת הפרשה הרגילה.

## קבצים במערכת

### Module:Parsha.lua
המודול הראשי שמכיל את הפונקציות הציבוריות.

### Module:HebrewDate.lua  
פונקציות עזר לחישובי תאריכים עבריים והמרות.

### Module:HolidayChecker.lua
בדיקת חגים וקריאות מיוחדות.

## דרכי שימוש

### קבלת פרשת השבוע הנוכחית
```
{{#invoke:Parsha|getParsha}}
```

### קבלת פרשה לתאריך מסוים
```
{{#invoke:Parsha|getParsha|date=2025-10-04}}
```

### בדיקה האם תאריך מסוים הוא חג
```
{{#invoke:Parsha|checkIfHoliday|date=2025-09-25}}
```

### קבלת מידע מפורט על תאריך
```
{{#invoke:Parsha|getDateInfo|date=2025-10-04}}
```

### רשימת כל הפרשיות
```
{{#invoke:Parsha|listAllParshiot}}
```

## חגים נתמכים

המודול מטפל בחגים הבאים שמחליפים את קריאת הפרשה הרגילה:

- **ראש השנה** (תשרי א'-ב')
- **יום כיפור** (תשרי י')
- **סוכות** (תשרי ט"ו - יום ראשון)
- **שמיני עצרת/שמחת תורה** (תשרי כ"ב-כ"ג)
- **פסח** (ניסן ט"ו - יום ראשון)
- **שביעי של פסח** (ניסן כ"א)
- **שבועות** (סיון ו')

לכל חג מוגדרת קריאת התורה, מפטיר והפטרה המתאימים.

## דוגמאות פלט

### פרשה רגילה:
```
'''פרשת בראשית'''
```

### חג:
```
'''חג: ראש השנה'''

'''קריאת התורה:''' וַיְדַבֵּר ה' אֶל־מֹשֶׁה לֵּאמֹר (במדבר כט, א-ו)

'''מפטיר:''' עקדת יצחק (בראשית כב, א-כד)

'''הפטרה:''' הנערה עקרה לא ילדה (שמואל א ב, א-י)
```

### מידע מפורט על תאריך:
```
'''תאריך גרגוריאני:''' 2025-10-04
'''תאריך עברי:''' 11 בתשרי 5786
'''יום בשבוע:''' שבת
'''שנה מעוברת:''' לא
```

## שיפורים במהדורה זו

### שימוש בספריות מדיה ויקי המקוריות
- המרת תאריכים מדויקת באמצעות `mw.language.new('he')`
- זיהוי אוטומטי של שנים מעוברות עבריות
- חישוב ימי שבוע מדויק

### פונקציות חדשות
- `getDateInfo()` - מידע מפורט על תאריך
- `getHebrewDateInfo()` - מידע עברי מפורט
- פונקציות עזר להמרת שמות חודשים

## הגבלות נוכחיות

1. **חישוב מחזור פרשיות**: עדיין בסיסי - צריך שיפור למדויק יותר
2. **צירוף פרשיות**: לא מטפל עדיין בצירוף פרשיות בשנים מסוימות
3. **שבתות מיוחדות**: לא כלולות עדיין

## הרחבות עתידיות

- הוספת שבתות מיוחדות (שבת שירה, זכור, פרה, החודש)
- שיפור חישוב התאריכים העבריים
- טיפול מדויק יותר במחזור הפרשיות השנתי
- הוספת חנוכה ופורים (לא מחליפים פרשה אבל משפיעים על ההפטרה)

## תלות בספריות מדיה ויקי

המודול משתמש בספריות הבאות:
- `Module:Arguments` - לעיבוד פרמטרים
- `Module:Yesno` - לעיבוד ערכי כן/לא
- פונקציות זמן בסיסיות של Lua/מדיה ויקי
